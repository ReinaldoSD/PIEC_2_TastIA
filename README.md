# 🍽️ TastIA

O **TastIA** é uma aplicação web que utiliza **Inteligência Artificial** para ajudar o usuário a descobrir receitas utilizando os ingredientes que possui em casa.

## 💡 Como funciona

O usuário pode:

- 📷 Fotografar os ingredientes disponíveis;
- 🤖 Identificar os ingredientes através de Visão Computacional;
- 📦 Armazenar os ingredientes em um inventário;
- 💬 Escrever o que deseja preparar em linguagem natural;
- 🍳 Receber uma receita com passo a passo;
- 🥤 Receber sugestões de bebidas que combinam com a refeição.

Por exemplo:

> "Uma comida leve para fazer em 15 minutos."

A IA utiliza o pedido do usuário e os ingredientes disponíveis para gerar uma receita possível de ser preparada.

## 🛠️ Tecnologias

- Python
- Flask
- HTML5
- Tailwind CSS
- JavaScript
- SQLite
- PyTorch
- Hugging Face Transformers

## 🤖 Inteligência Artificial

O projeto utiliza IA para:

- **Visão Computacional:** identificar os ingredientes nas imagens.
- **Geração de receitas:** criar receitas a partir dos ingredientes e do pedido do usuário.
- **Sugestão de bebidas:** recomendar bebidas compatíveis com a refeição.
